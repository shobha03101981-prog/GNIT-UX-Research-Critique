GNIT Website – UX Research & Interface Critique

Project Overview

This project focuses on evaluating the user experience (UX) of the Guru Nanak Institute of Technology (GNIT) website.

The objective is to identify usability issues, understand student difficulties, evaluate the existing interface using UX heuristics, and suggest practical design improvements.

Project Objectives

- Analyse at least five screens or states of the GNIT website.
- Identify usability and navigation problems.
- Evaluate the interface using five usability principles.
- Develop a primary research question.
- Define assumptions that require user validation.
- Recommend user-centred design improvements.

Website Under Review

Institution: Guru Nanak Institute of Technology (GNIT)
Website: https://gnit.ac.in/

Initial UX Finding

UX-01: Website Availability During High-Traffic Periods

Category: Performance & Reliability

Observation: The website reportedly fails to open frequently during examination and result announcement periods.

Potential User Impact:

- Students may be unable to access important academic information.
- Repeated attempts to open the website may cause frustration.
- Students may lose confidence in the availability of online information.

Proposed Improvement:

- Improve website reliability during high-demand periods.
- Display meaningful error and retry messages.
- Optimise website loading and access to important notices.

Validation Status: Pending further evidence and student feedback.

UX Heuristic Evaluation

The interface will be evaluated using:

1. Clarity
2. Feedback
3. Error Prevention
4. Accessibility
5. Trust

Primary Research Question

How might we help GNIT students access important academic information reliably and easily through the institution's website?
