# GNIT Website – UX Evidence

This folder contains screenshots and usability observations from the GNIT official website.

## UX Findings

- UX-01: Website availability during peak academic periods.
- UX-02: Floating counselling widget overlaps mobile navigation.
- UX-03: Incomplete dashboard icon rendering.
- UX-04: Repeated automatic admission enquiry popup.
- UX-05: LMS portal displays a blank white page.
- UX-06: Unexpected back navigation between portals.
- UX-07: Unexpected redirect after switching to Desktop Site.

## Evidence Collection

Original screenshots are stored separately in this folder and labelled with their corresponding UX finding IDs.
