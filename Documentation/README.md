GNIT Website – UX Audit Documentation

1. Project Overview

This project evaluates the usability and accessibility of the GNIT official website and its connected student portals.

Website: https://gnit.ac.in/

2. Heuristic Evaluation

The interface is evaluated using five usability principles:

- Clarity: Are information and navigation options easy to understand?
- Feedback: Does the system respond clearly to user actions?
- Error Prevention: Does the interface prevent unexpected errors or loss of progress?
- Accessibility: Can users access and understand the interface across devices?
- Trust: Does the website provide reliable and predictable experiences?

3. UX Findings

The initial audit includes seven candidate findings:

- UX-01: Website availability during peak academic periods.
- UX-02: Mobile navigation overlap.
- UX-03: Incomplete dashboard icon rendering.
- UX-04: Repeated admission enquiry popup.
- UX-05: Blank LMS page.
- UX-06: Unexpected back navigation between portals.
- UX-07: Redirect after switching to Desktop Site.

4. Severity Assessment

Findings will be prioritised based on:

- Impact on students.
- Frequency of occurrence.
- Difficulty in completing tasks.
- Risk of losing progress or important information.

5. Design Recommendations

- Improve mobile navigation and responsive layouts.
- Provide clear loading, error and retry messages.
- Maintain consistent navigation across connected portals.
- Prevent unnecessary popups from interrupting users.
- Improve icon consistency and accessibility.
- Preserve form data during navigation or display-mode changes.

6. Limitations

These are preliminary observations based on available screenshots and user-reported experiences. Technical causes and the frequency of each issue have not yet been independently verified.

7. Project Status

Initial UX audit documented. Further evidence collection, validation and redesign are in progress.
